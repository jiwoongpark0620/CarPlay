# Carlinkit T2C SE CarPlay 클라이언트

Carlinkit T2C SE(펌웨어 26081414.3075.1, 브랜치 3075)를 테슬라에서 쓸 때 생기는 순정 웹 화면 문제를 해결하기 위한 클라이언트. 순정 어댑터에 직접 연결하며, 어댑터 펌웨어는 건드리지 않는다.

* Apple CarPlay 기준으로 만들었으며 Android Auto 동작은 확인하지 않음.

## 해결하는 문제 (2026.10.20, 펌웨어 26081414.3075.1 기준)

- **화면 잘림**: 테슬라 소프트웨어 2026.26 이후 브라우저 화면 크기가 바뀌어 순정 페이지의 우측이 잘리는 문제
- **누적 딜레이**: 순정 페이지에서 사용할수록 화면 지연이 계속 늘어나 새로고침해야 하는 문제

## 사용법
1. Carlinkit을 차량에 세팅 (블루투스 및 WiFi 연결)
2. https://www.tespush.com/ 에 접속하여 Carplay 화면 출력 확인 (화면 잘린 상태)
3. https://jiwoongpark0620.github.io/CarPlay/ 로 접속
4. 업데이트가 완료될 동안 잠시 대기 (1.4 MB 다운로드, 인터넷 상황에 따라서 최대 2분정도 소요)
(tespush.com 창이 열려있는 경우, 화면이 나오지 않기 때문에 탭을 무조건 닫아두어야 함)

## 알아둘 점
해상도·프레임레이트는 어댑터 설정이다. 순정 페이지의 AutoKit 앱에서 바꾸면 이 클라이언트에서도 그대로 유지된다.
차량에서 이 펌웨어는 CarPlay 세션을 960×756으로 고정한다. 페이지 쪽에서 해상도(아이콘 크기)를 바꿀 방법은 없다.
순정 페이지로 돌아가 검은 화면이 나오면, 어댑터 모드가 다른 방식으로 남아 있는 것이다. 순정 설정에서 모드를 바꾼다.
