# Carlinkit T2C SE CarPlay 클라이언트

Carlinkit T2C SE(펌웨어 `26081414.3075.1`, 브랜치 3075)를 테슬라에서 쓸 때 생기는 순정 웹 화면 문제를 해결하기 위한 클라이언트.
순정 어댑터에 직접 연결하며, 어댑터 펌웨어는 건드리지 않는다.

\* Apple CarPlay 기준으로 만들었으며 Android Auto 동작은 확인하지 않음.

## 해결하는 문제 (2026.10.20, 펌웨어 26081414.3075.1 기준)

- **화면 잘림**: 테슬라 소프트웨어 2026.26 이후 브라우저 화면 크기가 바뀌어 순정 페이지의 우측이 잘리는 문제
- **누적 딜레이**: 순정 페이지에서 사용할수록 화면 지연이 계속 늘어나 새로고침해야 하는 문제

## 사용법

1. Carlinkit을 차량에 세팅한다 (블루투스 및 Wi‑Fi 연결). 테슬라 Wi‑Fi 설정에서 **주행 중 연결 유지**를 켠다.
2. <https://tespush.com/> 에 접속해 CarPlay 화면이 나오는지 확인한다 (우측이 잘린 상태).
   어댑터 초기 설정이 끝났는지를 이 클라이언트와 독립적으로 확인하는 단계다.
3. **tespush.com 탭을 닫는다.** 어댑터는 마지막에 연결한 화면 하나에만 응답하므로, 열려 있으면 이 클라이언트에 화면이 나오지 않는다.
4. <https://jiwoongpark0620.github.io/CarPlay/> 에 접속해 북마크한다.
   - 첫 접속은 어댑터의 블루투스 테더링(느린 인터넷)으로 페이지를 받으므로 10초 내외 걸린다.
   - 이때 페이지 전체(약 25 KB)가 브라우저에 저장되어, 이후로는 인터넷이 안 되거나 느려도 바로 열린다.

## 동작 방식

- **화면**: 어댑터 하드웨어가 만든 JPEG 스트림(`video.jpg`)을 화면 크기에 맞춰 표시한다. 순정 페이지와 같은 경로라 기본 지연도 같다.
- **지연 누적 방지**: 정해진 주기마다 스트림을 새로 연다. 브라우저는 새 스트림의 첫 장이 올 때까지 이전 화면을 유지한다.
- **터치·주간/야간**: 어댑터 WebSocket(`wss://tespush.com/`)으로 보낸다.
- **모드 전환**: 어댑터가 H.264 모드로 되어 있으면 사진(JPEG) 모드로 바꾼다. AutoKit에서 정한 해상도는 유지되며, 이때만 처음 한 번 CarPlay 세션이 재시작된다(약 20초).

## 옵션

- `?refresh=15` : 스트림을 새로 여는 주기(초, 기본 15). 지연이 쌓이면 줄이고, 화면 전환이 거슬리면 늘린다.
- `?fit=contain` : JPEG를 늘리지 않고 원래 비율로 표시 (기본은 화면에 맞춰 늘림)
- `?log=1` : 이벤트 로그 표시 (`boot`, `sw installed`, `link`, `size` 등)

## 알아둘 점

- **해상도·프레임레이트**는 어댑터 설정이다. 순정 페이지의 AutoKit 앱에서 바꾸면 이 클라이언트에서도 그대로 유지된다.
- 차량에서 이 펌웨어는 CarPlay 세션 크기를 고정한다. 페이지 쪽에서 아이콘 크기를 바꿀 방법은 없다.
- **업데이트**: 파일을 고치면 `sw.js`의 `CACHE` 값을 바꾼다. 다음 접속 때 새 버전을 받아 자동으로 새로고침된다.

## 파일

- `index.html` : 페이지
- `js/link.js` : 어댑터 WebSocket 연결 (메시지 형식은 파일 머리말 참고)
- `js/client.js` : 화면 표시, 터치, 모드 전환, 오프라인 사본 등록
- `sw.js` : 오프라인 사본(서비스 워커)
